# Son iPhone kurulumu

Güncel kaynaklardan yeni Release iOS çıktısı alındı, Xcode ile derlenip imzalandı. Profil geçerliliği, imzalama yetkileri ve cihaz kaydı doğrulandı. Mevcut uygulama kaldırılmadan üzerine kuruldu. İlk açma denemesindeki geçici iOS güven hatasının ardından tekrar başlatma başarılı oldu; başlatılan işlem cihazdan sorgulanarak çalışmaya devam ettiği doğrulandı.

verification.json derleme yollarını ve kaynak/uygulama hashlerini, install.json ve launch.json başarılı cihaz sonuçlarını içerir. Bu kurulum adımında fiziksel dokunma ve oyun içi görsel kontrol yapılmadı.
