# Çimde 2 saniye sonra parçalanma

GrassLifetime 10 saniyeden 2 saniyeye indirildi. Süre topun çime ilk fiziksel temasında başlar; oyun duraklatıldığında durur. İkinci saniyede mevcut 20 parçalı animasyon başlar. Animasyonun kendi süresi 1,1 saniyedir. Tahtada durunca/atış bitince parçalanma, çim sürtünmesi ve parçaların sekmesi değişmedi.

Unity 6000.3.24f1 macOS derlemesi ve gerçek Unity atışıyla 34 kontrol geçti. Gerçek zamanlayıcı hızlandırılmadan 2 saniye öncesinde topun sağlam kaldığı, 2,0–2,1 saniye arasında parçalanmanın başladığı, duraklatma, çim sürtünmesi ve temizleme doğrulandı. Test tercihleri geri yüklendi. Fiziksel iPhone testi yapılmadı.
