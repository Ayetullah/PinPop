# Nişan çemberi düzenlemesi

Çemberin içindeki eski merkez/ayak izi çizimleri kaldırıldı. Nişan noktaları, çemberin dış kenarı ve nokta yarıçapı üzerinden ekran uzayında dışarıda tutuluyor. Çember dış çapı bowling topunun gerçek çapına (.78 dünya birimi) bağlı; maksimum güç parlaması çapı büyütmüyor.

Unity 6000.3.24f1 geliştirme oynatıcısında 343 kontrol geçti. %25, %60, %100 çekme ve 42/55/70 FOV kontrollerinde çember içindeki nokta sayısı sıfır; ölçülen çember çapları hedef derinliğindeki topun çapıyla eşleşti (67.37 / 49.68 / 36.93 piksel). Ekran görüntüleri incelendi.

Fiziksel iPhone kontrolü yapılmadı: kullanıcı şu anda cihazı bağlayamıyor. iOS Release derlemesi başarılı; uygulama imzası doğrulandı. Geliştirme kontrol araçları Release sürümünden çıkarıldı. Kurulum paketi: `Builds/iOSReleaseDerivedData/Build/Products/Release-iphoneos/PinPop.app`. Canlı reklam kimlikleri değiştirilmedi.
