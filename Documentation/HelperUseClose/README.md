# Yardımcı kullanımından sonra kapatma

- Satın alma, yardımcı popup'ını açık tutar.
- Başarılı **Kullan** işlemi (renk/figür seçimi dahil) yardımcıyı uygular, bir stok tüketir, popup'ı kapatır ve oyunu sürdürür.
- Başarısız kullanım pencereyi açık ve oyunu duraklatılmış tutar; kaynak tüketmez. × ile vazgeçme korunur.

Unity macOS oynatıcısında dört yardımcı için Türkçe/English ve 320×568, 390×844, 1170×2532 boyutlarında 24 satın al–kullan akışı doğrulandı. Gerçek UI raycast ile satın alma/kullanma; tek stok tüketimi; doğru etki; ekstra coin veya hamle harcanmaması; kullanım hatasında açık kalma kontrol edildi.

**289 kontrol geçti, 0 hata.** Önceki oyuncu kayıtları geri yüklendi.
