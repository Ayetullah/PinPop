# Yeni oyun başlığı yerleşimi

Coin sol üstteki eski Hamle alanına taşındı. Hamle etiketi ve sayısı bölüm başlığının altında, önceki progressbarın hemen altındaki sıraya alındı. Progressbar ve toplanan/toplam duba sayacı oluşturulmuyor; eski güncelleme referansları kaldırıldı. Yardımcı ikonları coin ikonuyla aynı sütunda, coin alanının altında sıralanıyor.

Yedi ekran boyutunda hizalama, güvenli alan, metin sığması ve oyun/animasyon arayüzü kontrolleri: 423 başarılı, 0 başarısız. Yeni yerleşimin ekran görüntüleri incelendi. Fiziksel iPhone testi yapılmadı.
